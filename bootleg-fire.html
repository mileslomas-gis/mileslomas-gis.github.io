The 2021 Bootleg Fire

Investigating burn severity, vegetation, and terrain in southern Oregon.

Read the analysis notebook ↗Open original map PDF

Project overview

This project uses pre- and post-fire Sentinel-2 imagery and elevation data to examine spatial patterns in burn severity. The Python workflow prepares raster data, calculates vegetation and burn-severity indices, and explores relationships among vegetation, elevation, terrain, and fire impacts.

Data

Sentinel-2 imagery and a digital elevation model.

Methods

Vegetation and burn-severity indices, statistical exploration, and machine learning.

Outputs

A Python analysis notebook, reusable workflow, and companion cartographic layout.

Companion cartography

A spatial view of the fire

The final map combines burn-severity mapping with supporting charts and statewide fire context.
